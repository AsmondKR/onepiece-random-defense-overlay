# 원피스 랜덤 디펜스 오버레이

원랜디(원피스 랜덤 디펜스, Warcraft III Reforged 커스텀 맵) 실시간 조합 추천 오버레이입니다.
신+ 클리어 기록 3만 판을 학습해 목표 상위별 지원 조합을 추천하고, 게임 위 오버레이로
패 수치·조합 단계·아이템 사용처를 실시간 안내합니다.

## 주요 기능

### 클리어 데이터 학습
- 티모지지 공개 클리어 기록(신·악몽)을 증분 수집해 목표 상위별 지원 채용률을 학습합니다.
- 항법 구조 반영: 1상위(바운티헌터·로얄로더)는 상위 1기 클리어만, 다상위(긴급소집 등)는
  상위 2기+ 클리어만 집계합니다.
- 취향 조건부 학습: 이미 짠 유닛(앵커)과 같이 쓰인 클리어만 골라 채용률을 재계산합니다.
- 강화 폼 rawcode 통합(발라티에 상디, 센고쿠 불멸 등)으로 표본 유실을 막습니다.
- 품질(적은 유닛 수 우대)·최신성(반감기 14일) 가중치, 표본 12판 미만은 수작업 테이블로 후퇴.

### 역할 파이프라인
- 물딜: 스턴 → 이감 102 → 방깎 211 코어. 마딜: 방깎 대신 마방깎, 단일↔끝딜 보완 규칙.
- 상위별 전용 프로필(니카 이감/노이감 이중 빌드, 키자루 특공/역발상 등)과 빌드 방향 선택.
- 오로성(나스쥬로/워큐리/새턴) 판별 효과에 따른 목표 보정.
- 배(해적선·고대의 배) 예약 상호배제, 특포 경합 상위 제외, 목박 필러 보정.

### 오버레이
- 추천 카드(채용률 근거 표기) · 현재 패 수치(아이템·그린블러드 부여 효과 포함) ·
  지금 조합 가능(맵에서 추출한 조합 단축키) · 긴급소집 와일드카드 · 희귀패/특수함 정리 ·
  그린블러드 사용처.
- 전역 단축키(기본 Caps Lock)로 게임 중 토글, 클릭 통과, 위치 저장.

### 패 인식
- **메모리 모드(권장)**: 검증된 TMO.GG 빌드(SHA-256 고정)로 워크 메모리 루트를 확인한 뒤
  읽기 전용으로 패를 인식합니다. 쓰기·주입·입력 자동화는 하지 않습니다.
- **화면 모드(대체)**: 화면 아이콘 템플릿 매칭. 티모지지 없이 사용할 수 있습니다.
- **수동 모드**: 전체 카탈로그에서 패를 직접 추가/제거.

## 실행

1. Windows에서 `OrandOverlay.exe`를 실행합니다 (.NET 8, 자체 포함 배포).
2. 목표 상위·항법·오로성을 고르면 추천이 시작됩니다.
3. 메모리 인식을 쓰려면 TMO.GG와 Warcraft III를 함께 실행합니다.

## 빌드

```bash
dotnet build -c Release
dotnet run --project SmokeTests -c Release   # 스모크 테스트
dotnet publish -c Release -r win-x64 --self-contained true -o publish
```

앱이 실행 중이라 bin이 잠겼다면 `-p:BaseOutputPath=bin-verify/`로 우회합니다.

## 안전 원칙

- 게임 프로세스는 **읽기 전용**(PROCESS_VM_READ)으로만 접근합니다.
- 메모리 쓰기, 코드 주입, 입력 자동화, 후킹을 하지 않습니다.
- 검증되지 않은 티모지지/워크 빌드에서는 메모리 인식이 스스로 꺼집니다(fail-closed).

## 고지

비공식 팬 도구입니다. 원피스 랜덤 디펜스 제작진, TMO.GG(티모지지)와 무관하며,
유닛 데이터와 클리어 기록은 티모지지 공개 API·공식 카탈로그를 출처로 합니다.
